## מבנה הפרויקט

```
index.html                 # הגרסה הבנויה — זה מה שמוגש ב-GitHub Pages
build.js                   # מאחד את src/*.js ל-index.html יחיד
src/core.js                # תשתית: ניווט, HUD, ניקוד, חנות, סאונד, מוזיקה
src/games-*.js             # משחקים לפי קטגוריה
src/styles.css             # עיצוב
publish-csb.js             # פרסום מהיר ל-CodeSandbox (אופציונלי)
```

## פיתוח

```bash
npm i lz-string        # רק אם משתמשים ב-publish-csb.js
node build.js          # בונה מחדש את index.html
```

אחרי שינוי בקוד, מריצים `node build.js` ודוחפים גם את `src/` וגם את `index.html`.
